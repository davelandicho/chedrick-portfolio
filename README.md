# Chedrick Salazar Portfolio

Static one-page portfolio built from the REVAMP E-PORTFOLIO Figma design.

- `index.html` page markup
- `styles.css` all styles (colors and fonts are CSS variables at the top; light and dark themes)
- `img/` portrait, icons and certificate images

Open `index.html` in a browser, or upload the folder to any static host (GitHub Pages, Netlify, Vercel).
